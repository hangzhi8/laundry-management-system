## 洗衣店订单管理系统

- src/main/resources/front/front：前台界面源码
- admin-vue：后台界面源码
- xiyidian：后台服务源码

## 项目技术

- 前台界面：html，css，js等；
- 后台界面：vue2，element-ui等；
- 后台服务：SpringBoot2，Mybatis-Plus，Mysql，jdk1.8，Maven等；

> 说明：
> 
> 前台界面(front)是html，css，js构建的静态型的项目，不需要编译，直接运行即可，直接放在后台服务的资源文件夹中运行，就不需要配置Nginx了
> 
> 后台界面(admin-vue)是vue2.0+element-ui构建的动态型项目，需要编译才能运行


## 准备：项目技术升级

**准备升级后前端技术**：

- Vue3

- Element-Plus
- Axios

- Pinia

- SpringBoot3
- Mybatis-Plus

参考项目及知识点：https://github.com/hangzhi7/SpringBoot-Demo
